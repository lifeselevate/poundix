# Poundix — Protótipo

Protótipo navegável (HTML único, sem backend) do SaaS de coleta e acompanhamento de visitantes de igreja.

## Como abrir
Abra o `index.html` no navegador. Os dados ficam no `localStorage` do próprio navegador.

## Áreas
- **Questionário** (público): uma pergunta por tela, WhatsApp e idade obrigatórios.
- **Painel da igreja**: Dashboard, Visitantes, Líderes e ministérios, Células, Distribuição, Mensagens, Editor do questionário, Configurações.
- **Área do líder**: atribuições de cada líder.
- **Admin Poundix**: cadastro de igrejas e faturamento (pago / não pago).

Em Configurações → "Gerar dados de exemplo" cria líderes, células e visitantes de teste.

## Observação
Protótipo de design e fluxo. Não há autenticação nem separação real de dados por igreja; isso pertence ao backend.
